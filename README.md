# Personal Introduction Website

A simple personal introduction website built with HTML and CSS.

## Features
- Personal introduction
- Profile image
- Skills section
- Social media links
- Contact information
- Dark theme with custom styling

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Clone or download the repository.
2. Open `index.html` in your web browser.
